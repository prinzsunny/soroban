# Soroban practice

An interactive Japanese abacus (soroban) for young learners: free play, a 10-lesson tutorial, a tutor with 10 levels and gentle mistake guidance, a "Little hands" mode for toddlers, listen-and-add drills (including mental math), and timed worksheets. Voice, finger technique and wooden bead sounds included.

Open it: https://prinzsunny.github.io/soroban/

Built with the [Anatomy](https://github.com/wheresryan22/anatomy) skill's drawing kit. It is a single self-contained `index.html` with no dependencies.
